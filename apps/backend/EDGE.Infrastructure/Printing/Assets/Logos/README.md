# Official Receipt Logos Directory

Place high-resolution logo image files in this directory to be automatically rendered in the Official Receipt QuestPDF template:

- `ph-seal.png` (or `.jpg` / `.svg`) - Republic of the Philippines / Coat of Arms Seal (Left Logo)
- `ntc-logo.png` (or `.jpg` / `.svg`) - National Telecommunications Commission Logo (Right Logo)

If these image files are not present in this folder, the template will automatically render clean, vector placeholder emblems so PDF generation never fails.
